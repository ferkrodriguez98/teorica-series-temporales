# Datos de la clase

| Archivo | Contenido | Fuente |
|---|---|---|
| subte_diario_total.csv | pasajeros por día, toda la red (vacío = día sin datos) | SBASE, molinetes, BA Data |
| subte_diario_linea.csv | pasajeros por día y línea | SBASE, BA Data |
| subte_diario_estacion.csv.gz | pasajeros por día, línea y estación | SBASE, BA Data |
| subte_15min_linea.csv.gz | pasajeros cada 15 minutos por línea | SBASE, BA Data |
| estaciones_subte.geojson | ubicación de las estaciones | BA Data |
| ecobici_diario.csv, ecobici_hora.csv | viajes de Ecobici por día y por hora | Ecobici, BA Data |
| ecobici_estaciones.csv | estaciones de Ecobici (tres sistemas: M 2014, A 2015-2018, B desde 2019) | Ecobici, BA Data |
| clima_diario.csv | lluvia y temperatura diarias en CABA | Open-Meteo (reanálisis ERA5) |
| feriados.csv | feriados y días no laborables 2013-2026, con su norma | decretos y leyes nacionales |
| ipc_mensual.csv | índice de precios (IPCBA hasta nov. 2016, INDEC desde dic. 2016) | DGEyC CABA, INDEC |
| precio_boleto_mensual.csv | tarifa del subte (primer escalón) por mes | resoluciones de SBASE |
| eventos_verificados.csv | días atípicos del subte con su explicación y fuente | prensa y normas citadas |
| dolar_blue.csv | dólar blue, venta | Bluelytics |
